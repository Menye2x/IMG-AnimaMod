About MotionFrame
MotionFrame is a client-side GIF/WebP animation viewer and frame modifier. GIF and animated WebP imports use the browser/local frame pipeline without requiring a remote decoder library. VIEW focuses on playback. MODIFY lets you reorder, duplicate, delete, retime, or replace frames. Replacement is accepted only when the aspect ratio matches the selected frame canvas. No image data is uploaded by this app.
